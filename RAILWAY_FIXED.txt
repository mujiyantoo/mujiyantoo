1️⃣  PUSH KE GITHUB
    Buka Terminal/Command Prompt, ketik:
    
    cd /path/ke/folder/project
    git add .
    git commit -m "Add Railway config"
    git push origin main

2️⃣  DEPLOY DI RAILWAY
    a. Buka: https://railway.app
    b. New Project → Deploy from GitHub
    c. Pilih repository Anda
    
    ⚠️  PENTING: Set ROOT DIRECTORY = "/backend"
    
    d. Add Variables:
       • MONGO_URL = (dari MongoDB Atlas)
       • DB_NAME = bin_bimbel
       • CORS_ORIGINS = *
    
    e. Klik Deploy!

3️⃣  SETUP MONGODB ATLAS (Gratis)
    a. https://mongodb.com/atlas
    b. Create cluster (pilih FREE tier)
    c. Get connection string
    d. Set sebagai MONGO_URL di Railway
