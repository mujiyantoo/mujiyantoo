LANGKAH SELANJUTNYA:

1. PUSH KE GITHUB:
   Buka VS Code Terminal (atau command prompt), ketik:
   
   git add .
   git commit -m "Add Railway configuration files"
   git push origin main

2. DEPLOY DI RAILWAY:
   a. Buka https://railway.app
   b. New Project → Deploy from GitHub
   c. Pilih repository Anda
   d. Set Root Directory = "/backend"
   e. Tambah Environment Variables:
      - MONGO_URL = (dari MongoDB Atlas)
      - DB_NAME = bin_bimbel
      - CORS_ORIGINS = *
   f. Deploy!

3. SETUP MONGODB ATLAS (Gratis):
   a. https://mongodb.com/atlas
   b. Buat cluster gratis
   c. Get connection string
   d. Set sebagai MONGO_URL di Railway
